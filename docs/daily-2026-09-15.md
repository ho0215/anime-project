## 1. Static → S3 (현우)

### 문제

`manage.py collectstatic`이 S3 storage로 직접 올라가며 **파일마다 `HeadObject`** 를 호출 → 랩 네트워크에서 사실상 멈춤 (Ctrl+C / KeyboardInterrupt).

### 해결

| 항목 | 내용 |
|------|------|
| PR | [#32](https://github.com/ho0215/anime-project/pull/32) (merged) |
| 스크립트 | `scripts/collectstatic-s3.sh` |
| 방식 | ① 버킷 env unset → 로컬 `./staticfiles/` collectstatic<br>② `aws s3 sync` → `s3://…/static/` |
| 문서 | `docs/static-s3.md` |
| values | `deploy/helm/aniverse/values-eks.yaml` 버킷명 반영 |

### 실제 버킷

```text
aniverse-static-679583587966-ap-northeast-2
```

### cp1 검증 결과

- static 파일 **1394개** 로컬 복사 후 sync 성공
- 프리픽스 확인: `admin/`, `ckeditor/`, `css/`, `deal/`, `img/`, `src/` …
- sample CSS URL 브라우저에서 원문 노출 (200) 확인

```bash
export AWS_STORAGE_BUCKET_NAME=aniverse-static-679583587966-ap-northeast-2
export AWS_S3_REGION_NAME=ap-northeast-2
./scripts/collectstatic-s3.sh
aws s3 ls "s3://${AWS_STORAGE_BUCKET_NAME}/static/" | head
```

### 아직 안 한 것

실행 중인 앱(EC2/Pod)에 아래 env를 넣고 재시작해야 HTML의 `{% static %}`이 S3 URL을 가리킨다.

```bash
AWS_STORAGE_BUCKET_NAME=aniverse-static-679583587966-ap-northeast-2
AWS_S3_REGION_NAME=ap-northeast-2
```

## 4. EKS 올려볼 수 있나?

**지금은 불가.**

| 필수 | 담당 | 상태 |
|------|------|------|
| EKS + 노드 그룹 | 서이 | ❌ infra에 리소스 없음 |
| 노드 IAM → ECR pull | 서이 | ❌ |
| EBS CSI + StorageClass | 서이 | ❌ (`values-eks`는 `gp3` 가정만) |
| secrets 주입 (Git 기본값 X) | 현우/윤주 | 클러스터 후 |
| Argo destination → EKS | 현우 | 스캐폴드만 (`kubernetes.default.svc` = 랩) |

첫 기동에 미뤄도 되는 것: ALB Ingress, IRSA, HPA/NP Helm 반영, Redis.

서이 확인 한 줄: **클러스터 UP 여부 + `kubectl get sc` 이름**.
